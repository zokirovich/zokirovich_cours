Windows OS da ishlaydiganlar uchun choco ni ham cmd orqali install qilib olganiz maqul hisoblanadi
choco nima hisoblanadi
-chocolatey - bu Windows uchun paket menejeri hisoblanadi. Bu dastur orqali siz turli xil dasturlarni osonlik bilan o'rnatishingiz mumkin. Masalan, Node.js, Git, VSCode va boshqa ko'plab dasturlarni choco orqali o'rnatishingiz mumkin.
-choco orqali dastur o'rnatish uchun quyidagi buyruqni cmd da yozishingiz mumkin:
choco install <dastur_nomi>

git ni ham install qilib olamiz keyinchalik bizga kerak dastur hisoblanadi
gitbash nima hisoblanadi

- Git Bash - bu Windows operatsion tizimida ishlaydigan Git buyruqlarini bajarish uchun ishlatiladigan terminal emulator hisoblanadi. Bu dastur orqali siz Git buyruqlarini bajarishingiz mumkin va bu dastur Windows foydalanuvchilari uchun qulaylik yaratadi.
- git bash ishlatishdan maqsad bu visuol korinish jihatdan cmd dan ancha yaxshi hisoblanadi. Shuningdek, git bash orqali siz Linux buyruqlarini ham bajarishingiz mumkin, bu esa dasturchilar uchun qulaylik yaratadi.

JS nima hisoblanadi

- JS (JavaScript) - bu veb-sahifalarni interaktiv qilish uchun ishlatiladigan dasturlash tili hisoblanadi. JS yordamida siz foydalanuvchi bilan o'zaro aloqada bo'lishingiz, sahifani dinamik qilish, ma'lumotlarni qayta ishlash va boshqa ko'plab funksiyalarni bajarishingiz mumkin.
  JS ning afzalliklari
- JS ning afzalliklari quyidagilar:

1. Veb-sahifalarni interaktiv qilish imkoniyati
2. Ma'lumotlarni qayta ishlash va manipulyatsiya qilish imkoniyati
3. Foydalanuvchi bilan o'zaro aloqada bo'lish imkoniyati
4. Kengaytirilgan kutubxonalar va ramkalar mavjudligi
